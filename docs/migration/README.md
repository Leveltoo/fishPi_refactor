# 原版迁移与统一验收

日期：2026-10-09。旧项目 `fishpi-desktop`，新项目 `fishpi-desktop-refactor-tauri`。

目标是先恢复旧版实际功能与交互，再讨论新增功能。本次六个 agent 直接在各自负责的模块并行实施，主线程负责 SDK、认证、缓存、重连、中心接线和整体验证。没有改旧项目、创建 worktree 或提交 Git。

## 当前状态

- 发布 SDK 已从 1.1.0 升到固定 1.1.1，Cargo.lock 已更新；没有使用本地 SDK path。
- 聊天室、私聊、红包、内容、桌面、扩展/导入已进行源码核对和一轮实现。各模块文档区分“已实现”和“待真实环境验收”。
- 自动化通过不等于所有原版功能迁移完成，不给无依据的完成百分比。
- 没有发送真实红包、扣积分、感谢/打赏、发表评论、清风明月或执行安装包。需要账号的功能由用户统一测试。

## 基础层修复

- keyring 明确启用各平台原生后端，修复默认 mock 造成的“保存成功但不能恢复”。
- 登录提交、退出和导入凭据串行；登录状态或会话已变化时不允许旧配置覆盖当前账号 token。
- 登录页有“导入旧配置”，写入凭据成功后走正常 auth_restore 校验，不读取或导入旧明文密码。
- 账号切换按 sessionGeneration 重新挂载业务宿主；注销主动关闭文章频道。
- 离线消息按账号目录隔离，读取失败或损坏不当作空文件覆盖，保存使用完整临时文件替换。
- 原公共离线文件没有所属账号，保留原文件但不自动归给任意账号；不同账号不能读取彼此私聊。
- 撤回写入有界 tombstone 并删除各缓存副本正文，防止迟到消息或旧缓存重新显示已撤回内容。
- 网络恢复/休眠唤醒/手动重连调用 SDK 原句柄 reconnect，保留 handler 和代次；锁外等待、超时有界、换号拒绝放回旧句柄。
- 重连报告带会话代次；部分私聊成功不伪装全部成功；页面只补查询，不重放写请求。
- 新增 IPC 注册检查，防止界面引用未注册命令；红包发送有独立注册与参数验证。
- 私聊发送/断开同锁校验账号与连接代次，pending 不冒充已连接；修复同级组件重复 key 导致的 A/B 切换 DOM 残留。
- 聊天室保存并重放真实在线/话题帧，换号或重建清空；卸载只清监听，共享连接由认证层关闭。手动断开携带所属代次，迟到建连不能作废新连接。
- 旧 cloud 收藏读取/添加/删除/上传/换行 TXT 导入导出补迁，服务器分组独立保留；密钥只在 Rust，未知写入必须显式只读刷新后再操作。
- 名片单次有界读取保留 SDK wire 映射并提取真实公开 MBTI，跟随 SDK 代理配置；没有提供 MBTI 编辑。
- 全局右键拦截不再提前取消业务菜单事件，修复消息/输入/收藏等 Radix 菜单无法打开。
- 设置与导入共用串行后端写入；屏蔽保存失败恢复旧内存值，前端导入刷新隔离防抖和迟到回包。

## 手工验收

请先关闭旧客户端，使用专门测试账号。涉及积分的动作只点击一次，出现“结果待确认”时先到社区核对，不重复提交。

1. 登录：用户名/密码/MFA、失败提示、显隐密码、回车焦点、重启恢复、退出后不恢复；A/B 换号无页面/缓存混用。未登录导入旧配置后校验身份，已登录导入不得替换 token。
2. 聊天室：文本/多行/中文输入法、光标插入、回复/取消/+1/复读、清屏/刷新/更早历史、话题、在线菜单/@/名片/屏蔽/特别关心、图片选择与粘贴、默认/收藏/服务器表情；云收藏 TXT 导入导出/右键增删、未知结果后刷新，不能同时用另一客户端保存收藏。
3. 特殊消息：天气图标、网易云卡片及点击策略、进出场、弹幕长度/颜色、自己的撤回/管理员入口、先撤回后历史和重启缓存不复活。
4. 私聊：列表/逐条未读、隐藏页面不误标已读、按用户名新建、快速 A/B 切换、历史分页、回复/光标/图片/表情、撤回、全局发出回显不进入错误会话、未知结果不重发。
5. 红包：拼手气/平分/专属/心跳/猜拳，默认值与边界、选择/校验收件人、猜拳三手势、打开未领取不标已领、领取列表/数额/再发一个；换号与超时不能假成功。
6. 内容：列表分页与返回位置、详情富文本/图片/链接、感谢确认、赞踩选择/取消/切换、未付费正文隐藏、打赏后真实解锁、实时评论、末页起向前加载、回复跳转、匿名/仅楼主/删除/感谢/赞踩。
7. 清风明月：分页、作者名片/用户列表、输入法/Enter 发送、成功回读保留旧页、失败保留草稿、未知结果不重发。原版没有的编辑/删除不是迁移缺口。
8. 通知/奖励：类别/关键词/特别关心开关、声音/系统通知/托盘、应用内“查看”、紧急公告、分类已读、活跃度、昨日奖励真实数额；签到查询不当作写入成功。
9. 音乐：0/1/2 策略、重复曲目、移出当前曲/按 ID 删除、清空时迟到解析、前后曲/循环/静音、歌曲外链、播放失败。
10. 桌面：最小化/关闭/关闭到托盘、托盘显示/退出/闪烁、老板键/冲突、置顶/透明、尺寸持久化、高 DPI 名片/公开 MBTI、图片缩放拖拽/复位/复制/外开，业务右键菜单。
11. 重连：断网后恢复、休眠唤醒、手动重连、重复点击；聊天室/当前私聊/文章补拉，旧代次推送不能污染当前账号。
12. 扩展/设置/更新：独立扩展入口、扫描/README/合法主页、主题切换与失效回退、旧配置屏蔽/关心/音乐/透明/快捷键、检查更新失败如实显示、下载后不自动安装。

## 尚未等价

- 旧 cloud 协议没有跨客户端 CAS，另一个客户端同时保存仍可能覆盖；`{code:0,data:""}` 不能区分无记录和服务端读取异常。真实云收藏读写尚未验收。
- 旧 Electron 插件的 activate/electron、Node webview、command、hooks、动态侧栏及读取 token 的运行时没有兼容。只读列表/README和受控主题不等于插件可运行。
- 旧 CSS 只映射已支持颜色变量；复杂布局、相对资源、自定义 selector 不保证视觉一致。
- 图片/@/红包仍使用主窗 overlay，旧独立窗口定位/置顶形态未全部复刻。
- Windows 系统通知点击回调未恢复；应用内“查看”与之不同。
- SDK 不暴露连接 open/close/error，运行中无消息不能用来断定掉线；显式 reconnect 有结果和状态事件。
- 签到写入不是旧客户端已有能力，原版与 SDK 都只提供状态查询；新版明确提示未签到，不把查询冒充写入成功。MBTI 读取已补迁，不再属于缺接口就停做的项。
- 网易云实际可播性取决于版权/网络；更新包签名、实际安装、非 Windows 平台尚未验收。
