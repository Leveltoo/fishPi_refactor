# 通知与活跃度对照

对照旧 Electron 客户端的消息提示、紧急公告、昨日活跃自动领取、窗口边缘活跃度和侧栏私聊未读。下面只记已经接上的行为，以及做不到或故意不同的地方。

## 已接上

- 通知分类开关在现有设置页：聊天室新消息、私聊、提及、回复（含评论）、系统公告、聊天室关键词正则，以及提示方式「新消息声音」「系统消息」。总开关 `notifyEnabled` 仍在。新字段默认关，旧设置文件缺这些字段时也保持关。
- 关闭的类别不响，也不弹系统通知。系统通知还要「系统消息」和总开关都打开。总开关关闭时，已有命令 `notify_show` 会拒绝发送。声音只看「新消息声音」，不看总开关。
- 聊天室听 `chatroom://msg`。只处理 `kind === "msg"`，跳过撤回和自己的消息。关键词命中时只提示这一条，不再加一条普通聊天室提示。
- 私聊听 `chat://notice` 里的 `newIdleChatMessage`。不把 `chat://msg` 再通知一次。预览截到 10 个字。
- 提及、回复、评论、系统公告听 `notice://refresh`。登录后会先拉一次这四类列表，只把当时的未读 id 记下来，不提示。之后的刷新才提示新未读。私聊通道上若再来一条 `refreshNotification`，会再拉一次列表；同一批未读不会提示两次。列表用已有 `notice_list`。回复开关同时覆盖 `reply` 和 `commented`。
- 声音用 Web Audio 短音，没有新增音频依赖。同一次通知列表刷新只响一声。
- 紧急公告：SDK 把 `warnBroadcast` 映成 `NoticeEventKind::Broadcast`，Bridge 再发 `notice://broadcast`（`content`、`who`）。壳层用可关闭的文本模态显示正文和发布者，正文按文本渲染，不用 HTML。活动页和私聊不再对这条事件 toast。
- 自动领取昨日活跃：设置快照已经读到，且 `autoReward` 为开时，这次登录只调用一次已有 `user_reward_liveness`。只有 `sum > 0` 才提示成功。积分为 0 或已领过则安静结束。结果不明用警告，失败用错误，都不写成已领取。设置还没读到就不领。同一次登录里后来才打开开关，不补领。默认关。
- 窗口四周活跃度用已有 `user_liveness`，间隔与活动页相同（10 分钟）。没有数值或命令缺失时不画条；命令缺失后停止轮询。返回 0 会画，因为 0 是真实数据。颜色沿用现有变量：达到 10 用 `--color-accent`，否则 `--color-brass`。
- 侧栏私聊未读是当前会话 `unread` 的合计。会话未读来自已有 `chat_unread` 和私聊里的增减，不另造计数。超过 99 显示 `99+`。私聊面板卸载时清成 0。

## 做不到

点击系统通知不能打开主窗口，也不能切到聊天室、私聊或活动通知。

`notify_show` 走 `tauri-plugin-notification` 2.4 的桌面 `show()`。它只把标题和正文交给 `notify-rust`，然后丢掉返回的句柄，没有点击回调，附加数据也不会带到通知上。现有命令没有点击载荷。没有把 `notify-rust` 加进依赖，也没有新的通知命令。因此这里不假装点击后会跳转。

## 和旧版不同

- 旧版「系统消息」不包含聊天室。这里在「聊天室新消息」和「系统消息」都打开时，聊天室发言也会弹系统通知。
- 旧版 @、回复、评论、系统公告不播放声音。这里在对应类别和「新消息声音」都打开时，同一次刷新响一声。
- 登录后第一次成功拉到提及、回复、评论、系统公告四类列表时，只把当时的未读 id 记下来，不提示，避免把历史未读一次弹完。这次基线不等待 `notice://refresh`，否则第一条刷新带来的新通知会被当成历史吞掉。之后出现的新未读才提示。四类里有一类失败，则这次不记基线，也不提示。
- 旧版 @ 只提示聊天室（`dataType === 38`）。现在的通知条目没有 `dataType`，未读 @ 都会提示。
- 旧版空正则会匹配所有聊天室消息。这里空正则不匹配任何消息。
- 非法或超长正则（超过 200 字）会被忽略，并用 `new RegExp` 判断，不当成代码执行。同一条非法规则只提示一次。设置页也会显示这不是合法正则。
- 旧版侧栏数字是未读会话条数。这里是各会话 `unread` 相加。
- 不包含旧版特别关心上线、红包提醒、聊天室屏蔽。屏蔽由另一处的 `chatroomFilters` 负责，这里不实现。

## 命令

`lib.rs` 没有追加命令。用的都是已经注册的命令：`notify_show`、`settings_get`、`settings_set`、`notice_list`、`user_liveness`、`user_reward_liveness`、`chat_unread`。
